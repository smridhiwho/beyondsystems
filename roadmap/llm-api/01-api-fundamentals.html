Basic API Call Structure

Most LLM APIs follow a similar pattern. Here's a complete example with OpenAI:

import openai
import os

# Authenticate with API key
client = openai.OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# Make a chat completion request
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain quantum computing in simple terms."}
    ],
    temperature=0.7,
    max_tokens=500
)

print(response.choices[0].message.content)

Prompt Engineering Basics

System Prompts

Set the AI's behavior and personality before the conversation starts:

messages = [
    {"role": "system", "content": "You are a senior Python developer. Respond with code examples in markdown format."},
    {"role": "user", "content": "How do I read a CSV file in Python?"}
]

Few-Shot Prompting

Provide examples to guide the model's response format:

messages = [
    {"role": "user", "content": """
    Translate the following English sentences to French:

    "hello" -> "bonjour"
    "goodbye" -> "au revoir"
    "thank you" -> ?"""}
]

Temperature and Sampling

Parameter Range Effect
temperature 0.0 - 2.0 Creativity vs. determinism (lower = more predictable)
top_p 0.0 - 1.0 Nucleus sampling for diversity
max_tokens 1 - 4096 Response length limit
frequency_penalty 0.0 - 2.0 Reduce repetitive responses

Error Handling

LLM APIs can fail. Handle errors gracefully:

from openai import OpenAI, OpenAIError
import time

def call_llm_safely(client, messages, max_retries=3):
    for attempt in range(max_retries):
        try:
            response = client.chat.completions.create(
                model="gpt-4o",
                messages=messages,
                temperature=0.7
            )
            return response.choices[0].message.content
            
        except OpenAIError as e:
            if attempt < max_retries - 1:
                wait_time = 2 ** attempt
                print(f"Rate limited, waiting {wait_time}s...")
                time.sleep(wait_time)
            else:
                raise e
        except Exception as e:
            print(f"Unexpected error: {e}")
            raise

# Usage
result = call_llm_safely(client, messages)
The first time your production app hits a rate limit, you'll understand why error handling isn't optional.
